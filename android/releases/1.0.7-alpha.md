# Chameleon Android 1.0.7-alpha

Эта версия исправляет подключение Android-клиента к серверу Chameleon 1.0.6 через мобильную сеть и relay/WireGuard ingress.

## Что изменено

- TLS ClientHello сделан компактным (X25519/P-256). Это устраняет обрывы первого handshake из-за слишком большого hybrid ML-KEM key share на мобильных сетях и HAProxy/WireGuard relay.
- Добавлены подробные Android Logcat этапы: remote preflight, SOCKS listener, TUN, tun2socks и причина остановки runtime.
- Ошибки remote transport теперь показывают transport, endpoint и фактическую причину (TLS handshake, certificate pin, timeout, QUIC и т.д.).
- Android preflight ждёт до 8 секунд для TLS и до 6 секунд для QUIC, чтобы мобильная сеть успевала проснуться и пройти relay/WireGuard hop.
- TLS preflight использует split-early для первого ClientHello; это синхронизирует проверку доступности с adaptive runtime и обходом DPI на мобильном relay-пути.

## Совместимость

- сервер Chameleon 1.0.6;
- wire protocol 1.0.x без изменений;
- Android API 23+, полный VPN/TUN режим — API 29+;
- профиль и PSK повторно импортировать не требуется.
