# Chameleon Android 1.0.8-alpha

Эта версия повторно публикует исправления подключения Android-клиента к серверу Chameleon 1.0.6 под новым номером версии, чтобы Android распознал APK как обновление.

## Что изменено

- TLS preflight применяет split-early к первому ClientHello, как и adaptive runtime. Это помогает мобильным сетям и DPI не отбрасывать первый TLS-пакет до запуска VPN listener.
- Сохранены компактный ClientHello X25519/P-256, увеличенные mobile preflight timeout и подробные stage/error логи из 1.0.7-alpha.

## Совместимость

- сервер Chameleon 1.0.6;
- wire protocol 1.0.x без изменений;
- Android API 23+, полный VPN/TUN режим — API 29+;
- профиль и PSK повторно импортировать не требуется.
