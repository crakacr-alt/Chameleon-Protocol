# Chameleon Android 1.1.0-alpha

Крупный Android/server релиз: Auth v2, настоящий Smart VPN и новый Inspector вместо старого локального Proxy.

## Auth v2

- Каждый клиент получает собственные `CHAMELEON_CLIENT_ID` + `CHAMELEON_CLIENT_SECRET`.
- Challenge-response не зависит от часов телефона.
- Сервер поддерживает enable/disable/expiry для отдельных клиентов.
- Legacy PSK остаётся временным fallback на том же listener, поэтому миграция не ломает старые клиенты.
- `chameleonctl` умеет создавать, включать, отключать и удалять Auth v2 клиентов.
- Installer создаёт `clients.json`, первый Auth v2 клиент и отдельный `client-profile-v2.txt`.
- WireGuard relay-скрипт создаёт `client-profile-relay-v2.txt`.

## Android modes

- Smart теперь использует настоящий Android VpnService/TUN и реально маршрутизирует трафик телефона.
- VPN остаётся strict Chameleon-only режимом для всего устройства.
- Старый Proxy заменён на Inspector: системный TUN + Chameleon + захват трафика.
- Режимы больше не маскируют локальный SOCKS как полноценный Android proxy.

## Inspector

- Захват пакетов выполняется на границе Android TUN -> tun2socks.
- Экспортируется стандартный DLT_RAW PCAP, открываемый в Wireshark.
- Live-окно показывает TCP/UDP потоки, IP/порт, объём и число пакетов.
- Android пытается сопоставить поток с UID/package приложения.
- Анализируются DNS query, TLS SNI и незашифрованный HTTP method.
- Capture включается только при явном запуске Inspector.
- Можно создать локальный Inspector CA и открыть штатный Android installer сертификата.
- Certificate pinning не обходится; HTTPS body interception в этом релизе не заявляется как готовое.

## Compatibility

- Android full-device Smart/Inspector/VPN требуют Android 10+.
- Старый PSK profile остаётся совместимым на время миграции.
- Auth v2 работает через TCP/TLS/QUIC stream и QUIC datagram paths.
