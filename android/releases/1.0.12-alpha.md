# Chameleon Android 1.0.12-alpha

Hotfix for Android TLS preflight after real-device testing.

## Что изменено

- Обычный TLS ClientHello теперь проверяется первым.
- `paced-split-mobile` и `split-early` используются только как fallback, если обычный TLS действительно не проходит.
- Исправлена вводящая в заблуждение строка о совместимости VPN: она больше не выглядит как детектор активного стороннего VPN.
- Остальные изменения 1.0.11-alpha сохранены: authenticated preflight, сохранение рабочего endpoint, persistent VPN errors и TLS-only relay profile.

## Причина

На реальном Android телефон успешно устанавливал TCP-соединение с ingress `80.86.216.169:443`, HAProxy передавал его через WireGuard к exit, но оба принудительно split-варианта TLS ClientHello зависали до PSK-аутентификации.

1.0.12-alpha возвращает direct-first порядок, который уже является базовой стратегией Chameleon: сначала не модифицировать рабочий TLS, затем применять обходные стратегии только при необходимости.

## Совместимость

- Wire protocol не изменён.
- Существующий PSK/TLS fingerprint остаются действительными.
- Server 1.0.x совместим.
