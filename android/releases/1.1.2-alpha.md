# Chameleon Android 1.1.2-alpha

Исправления подключения Android, проверка VPN через два сервера и расширенный Inspector.

- Альтернативный порт 443/9443 проверяется с тем же TLS pin и Auth v2.
- Doctor поддерживает Auth v2 и показывает причину сбоя.
- Inspector: отдельные пакеты, HEX/ASCII, фильтр, пауза просмотра и экспорт PCAP. HTTPS остаётся зашифрованным; кнопка установки CA удалена.
- Установщик: роли Exit/Intermediate, сопряжение, согласованные порты и пути к профилям клиента.

## Установка на телефон

Скачайте `Chameleon-Android-1.1.2-alpha.apk` из Assets и откройте его на Android.
Это release-сборка `io.chameleon.android`; VPN требует Android 10+.
Импортируйте свой профиль Auth v2 и выберите VPN. Профиль содержит секрет доступа,
поэтому его нет в публичных Assets. После подключения внешний IP должен быть IP Exit.

## Установка сервера

Комплект `Chameleon-server-installer.tar.gz` содержит исходники и `install.sh`.
Распакуйте на VPS и запустите `sudo bash install.sh`. Выберите Exit или Intermediate;
на Exit завершите Pair. Пункт Status показывает путь к профилю
`/etc/chameleon/client-profile-relay-v2.txt`.
Подробное руководство: `docs/network_installer.md`.

## Проверено

Android-эмулятор API 36.1: DNS, HTTPS через TLS и принудительный QUIC, обычный UDP STUN.
Отдельное приложение с другим UID подтвердило IP Exit для TCP и UDP. PCAP разобран
Wireshark/tshark; экран отдельных пакетов и HEX/ASCII проверен.

Физический телефон и сеть оператора пока не проверены. Полная установка на двух
чистых VPS пока не проверялась. Inspector не реализует все декодеры Wireshark,
сборку TCP-потоков или расшифровку HTTPS.
