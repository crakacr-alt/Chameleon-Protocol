# Chameleon Android 1.1.1-alpha

Hotfix первого подключения Android при активном Happ/V2Ray/другом системном VPN.

## Fixed

- Chameleon сначала занимает системный VPN-слот и создаёт свой TUN.
- Пакет Chameleon исключается из собственного VPN до remote preflight.
- Проверка ingress/Auth v2 идёт через реальный Wi-Fi/мобильный underlay, а не через старый VPN-интерфейс.
- Импорт профиля больше не выдаёт ложную ошибку сервера из-за активного стороннего VPN.
- Doctor показывает наличие другого VPN и откладывает remote probe до запуска Chameleon.
- Doctor отдельно показывает состояние Chameleon VPN и стороннего VPN.

## Topology

Серверная схема не менялась:

Android -> 80.86.216.169:443 (ingress) -> WireGuard -> 88.210.20.127 (exit) -> Internet.

Профиль Auth v2 от 1.1.0-alpha остаётся совместимым; новый client secret не требуется.
