# Chameleon Android 1.0.0-alpha.1

Первый открытый Android-клиент Chameleon Protocol.

## Что работает

- Android 6.0+ (API 23+);
- общий Go networking core Chameleon Protocol 1.0.0 через gomobile;
- импорт `client-profile.txt`, создаваемого VPS installer;
- одна большая кнопка запуска/остановки;
- Smart mode;
- Proxy mode;
- локальный SOCKS5 `127.0.0.1:1080`;
- работа рядом с Tailscale: приложение не создаёт Android `VpnService`;
- foreground service, чтобы proxy не зависел от открытого экрана;
- список Android-релизов;
- показ изменений по версиям;
- проверка обновлений через публичный GitHub index;
- скачивание APK через Android DownloadManager;
- SHA-256 проверка перед установкой;
- передача установки штатному Android Package Installer.

## Почему установка обновления требует подтверждения

Обычное Android-приложение не имеет права молча заменить свой APK.
Chameleon может сам обнаружить и скачать обновление, но финальную установку
подтверждает пользователь в системном окне Android.

## Ограничения alpha

Это proxy-клиент, а не системный VPN.

Приложения должны уметь использовать SOCKS5 `127.0.0.1:1080` либо получать
proxy-настройку через другой локальный механизм. Это специально сохраняет
совместимость с Tailscale, который может продолжать занимать Android VPN slot.

Полноценный optional `VpnService`, per-app routing и системный transparent mode
остаются целью Android 1.2.

## Подпись alpha

CI использует отдельный alpha signing key, хранящийся в закрытом GitHub Actions
cache. Это удобный канал тестирования, но не долгосрочная схема доверия.

Перед стабильным Android 1.2 будет создан постоянный release signing key,
хранящийся только в GitHub Secrets. Переход с alpha-подписи на stable-подпись
может потребовать один раз удалить alpha APK и установить stable APK заново.
