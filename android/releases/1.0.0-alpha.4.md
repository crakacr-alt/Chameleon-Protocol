# Chameleon Android 1.0.0-alpha.4

Исправление клиентской части после end-to-end диагностики двухсерверной схемы.

## Fixed

- устранена гонка жизненного цикла между sidecar `ChameleonService` и `ChameleonVpnService`;
- runtime получил владельца (`sidecar` / `vpn`), поэтому запоздалый STOP старого сервиса не может остановить новый SOCKS5;
- остановка runtime стала синхронной перед передачей `127.0.0.1:1080` другому режиму;
- статус VPN становится `connected` только после реальной готовности SOCKS5, TUN и hev-socks5-tunnel;
- Android Doctor делает настоящий TCP self-check локального SOCKS listener вместо проверки только внутреннего флага;
- adaptive carrier/DPI state теперь изолирован по endpoint/profile, чтобы история недоступного старого exit не переносилась на новый relay;
- source Windows installer больше не регистрирует консольный клиент как SCM service: используется Scheduled Task.

## Upgrade

Обычная установка alpha.4 поверх alpha.3 сохраняет внутренний `client.json`, PSK, выбранный режим и пользовательские данные приложения. Повторно импортировать relay profile не требуется.

Protocol core: 1.0.5. Wire protocol остаётся совместимым с 1.0.x.
