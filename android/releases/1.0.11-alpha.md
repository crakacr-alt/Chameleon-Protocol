# Chameleon Android 1.0.11-alpha

Этот релиз исправляет именно Android-подключение к существующей двухсерверной схеме и делает проверку профиля похожей на привычный flow VPN-клиентов: импорт -> проверка сервера -> подтверждённая авторизация -> подключение.

## Что изменено

- После импорта профиль сразу проходит authenticated preflight с PSK и TLS pin.
- Успешно проверенный endpoint и transport сохраняются и используются при следующем запуске VPN.
- На Android 10+ новый клиент по умолчанию предлагает режим `VPN — весь телефон`, а не локальный Smart sidecar.
- Ошибка запуска VPN сохраняется в приложении и остаётся видимой после остановки foreground service.
- Если QUIC/UDP preflight провалился, недоступный QUIC endpoint удаляется из подготовленного mobile config, чтобы DNS не платил повторный таймаут.
- Явный TLS-only профиль больше не получает выдуманные TCP/QUIC endpoints.
- Генераторы server/relay profile больше не рекламируют raw TCP на порту, где реально работает TLS front.
- Legacy-профили только с `CHAMELEON_SERVER` по-прежнему поддерживаются и сохраняют старое all-carrier поведение.

## Проверенная схема

Тестовая схема этого релиза:

```text
Android -> TLS 80.86.216.169:443
        -> HAProxy ingress
        -> WireGuard 10.77.0.1 <-> 10.77.0.2
        -> Chameleon TLS :9443
        -> exit 88.210.20.127
```

Authenticated SOCKS test через ingress вернул внешний exit IP `88.210.20.127`.

## Совместимость

- Android 10+ рекомендуется для полного VPN/TUN режима.
- Android 6+ сохраняет Smart/Proxy sidecar.
- Wire protocol не менялся; существующий PSK и TLS certificate остаются действительными.
- Серверный Chameleon можно обновлять независимо; старые профили не удаляются.
