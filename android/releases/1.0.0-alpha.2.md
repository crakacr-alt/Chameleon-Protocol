# Chameleon Android 1.0.0-alpha.2

Второй Android alpha с исправлениями режима и быстрым запуском Smart.

## Что изменилось

- новый значок Chameleon вместо временного символа;
- переключение Smart / Proxy сразу сохраняет режим — повторно импортировать профиль больше не нужно;
- верхняя строка показывает текущий режим и совместимость с другим VPN без привязки к Tailscale;
- запуск SOCKS5 теперь подтверждается только после реального bind `127.0.0.1:1080`, поэтому приложение не показывает ложное «Подключено» при занятом порту;
- действие Smart прямо в постоянном уведомлении;
- плитка Chameleon Smart для панели быстрых настроек Android;
- виджет рабочего стола для быстрого включения/выключения Smart;
- диагностика показывает реальное состояние listener;
- сохранён GitHub update channel с SHA-256 проверкой APK.

## Совместимость

- Android 6.0+ (API 23+);
- Quick Settings tile доступна на Android 7.0+;
- Protocol 1.0.2;
- Smart и Proxy остаются локальными SOCKS5 режимами.

## Ограничение alpha.2

System-wide Android `VpnService` в этот APK не объявляется. Поэтому alpha.2
не заявляется как прозрачный VPN для всех приложений телефона. Полноценный TUN
data path должен выпускаться отдельно только после end-to-end тестов, чтобы не
выдавать экспериментальную заглушку за рабочий VPN.
