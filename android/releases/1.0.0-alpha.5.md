# Chameleon Android 1.0.0-alpha.5

Главная цель alpha.5 — сделать full-device VPN устойчивым на мобильных сетях, где нестандартный UDP/TCP порт доступен частично или фильтруется.

## Исправлено

- перед запуском TUN Android выполняет реальную удалённую проверку Chameleon transport, а не считает VPN готовым только по localhost SOCKS;
- TCP carrier умеет автоматически использовать стандартный TLS ingress на 443, если профильный нестандартный порт недоступен;
- для VPN выбирается реально доступный TCP transport до поднятия системного VPN;
- QUIC probe больше не закрывает QUIC connection раньше, чем клиент успевает получить финальный authenticated status;
- при недоступном QUIC UDP системный DNS не теряется: DNS/UDP безопасно переносится через Chameleon TCP/TLS как DNS-over-TCP;
- non-DNS UDP при fallback не уходит напрямую, поэтому Proxy/VPN режим не создаёт скрытую UDP-утечку;
- QUIC UDP получает короткий cooldown после сетевой блокировки, чтобы каждый DNS-запрос не ждал полный UDP timeout;
- Android TUN MTU снижен до 1400 для более безопасной работы поверх мобильных сетей и дополнительного relay/WireGuard слоя;
- Doctor теперь действительно проверяет удалённый transport и показывает выбранный TCP путь и состояние UDP fallback.

## Совместимость

- Android 6+ для приложения, Android 10+ для full-device VPN;
- protocol/client core 1.0.6;
- wire format совместим с существующим Server 1.0.x;
- существующий client-profile и PSK сохраняются, повторный импорт после обновления не требуется.
