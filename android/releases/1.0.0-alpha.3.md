# Chameleon Android 1.0.0-alpha.3

Третий Android alpha добавляет настоящий системный VPN/TUN режим поверх того
же открытого Chameleon core.

## Что добавлено

- новый режим **VPN — весь телефон через Chameleon**;
- Android `VpnService` создаёт системный IPv4/IPv6 TUN;
- open-source `hev-socks5-tunnel 2.18.0` преобразует TUN-пакеты в локальный
  Chameleon SOCKS5 `127.0.0.1:1080`;
- dependency AAR закреплён по версии и SHA-256 в GitHub Actions;
- VPN mode принудительно использует Chameleon Proxy core, чтобы captured traffic
  не уходил через direct carrier;
- DNS-запросы из TUN также идут через локальный SOCKS/Chameleon path;
- отдельное постоянное уведомление VPN с кнопкой выключения;
- Quick Settings tile и виджет остаются быстрыми переключателями Smart;
- tile/widget понимают состояние VPN и могут его остановить.

## Совместимость режимов

- **Smart** — локальный sidecar, другой Android VPN может оставаться включён;
- **Proxy** — локальный Chameleon-only sidecar;
- **VPN** — системный `VpnService`, поэтому Android не держит одновременно
  второй независимый VPN service.

## Реализация

TUN data path использует MIT-licensed open-source project
`heiher/hev-socks5-tunnel` версии 2.18.0. В CI скачивается официальный AAR и
перед сборкой проверяется SHA-256:

`15ec8ed121663b562c99caa5bb602d1009f24e5b09e733438b81988f12feaaab`

Весь Chameleon transport selection, PSK, QUIC/TLS/TCP и route learning остаются
в общем Go core проекта.

## Ограничения alpha

- приложение устанавливается на Android 6.0+, но новый VPN/TUN mode требует Android 10+ (API 29) из-за закреплённой native tun2socks сборки;
- Smart/Proxy остаются доступны на Android 6.0+;
- это ранний alpha, поэтому нужен реальный тест на устройстве после установки;
- VPN mode не может сделать полностью недостижимый публичный IP достижимым:
  для такого случая используйте новый relay/ingress profile;
- второй Android VPN service одновременно с Chameleon VPN mode не поддерживается
  ограничениями Android.
